# English Growth

## Overview
Use this skill when the goal is long-term language growth from authentic English texts.

Core principle:
> Read the real text first. Identify the actual barrier. Build only the support the learner needs. Retrieve it later. Return to the text.

## Learner Profile Relevant to Language Growth
- The learner is a Grade 4 multilingual learner.
- They can sometimes read aloud without understanding.
- Vocabulary knowledge can limit sentence and text comprehension.
- Some barriers are chunks/collocations, not isolated words.
- Multisyllabic decoding can be slow.
- Sentence meaning and gist may need explicit support.
- Fluency and comprehension must be measured separately.

## Core Route
AUTHENTIC TEXT → COLD READ → DECODE → FLUENCY → WORD → CHUNK → SENTENCE MEANING → GIST → RETRIEVAL → REREAD → TRANSFER

Skip stages already mastered.

## Cold Read First
Before model audio, definitions, Chinese translation, chunking, pictures, or frames, collect baseline evidence.

Teacher marks:
Accurate / Slow / Misread / Stuck / Self-corrected / Can read but does not know meaning.

## Distinguish the Barrier
- Hard to read → Decoding / Fluency
- Can read, does not know meaning → Vocabulary
- Knows words, not phrase → Chunk / Collocation
- Knows words/chunks, not sentence → Sentence Meaning
- Understands sentences, not big idea → Gist
- Understood before, cannot recall → Retention
- Can do with support, not alone → Independence

## Decode Coach
The learner tries → useful phonics/syllable/morphology support → retry word → retry original sentence.
Grade 4 appropriate; no fake syllabification.

## Fluency Coach
COLD READ → NOTICE → DECODE DIFFICULT WORDS → PHRASE READING → LISTEN & READ → PAUSE & REPEAT → READ BY MYSELF → FINAL READ → MEANING CHECK

Track:
Decoding Accuracy / Automaticity / Phrasing / Prosody / Comprehension / Independence

## Vocabulary
Use:
SEE → SAY → MEAN → CONTEXT → RETRIEVE → USE → RETURN

Prefer child-friendly English first; Chinese only if needed.

## Chunks
Treat chunks as first-class learning objects:
in charge of / believe in / far and wide / be prepared to / as a result

Use:
WHOLE MEANING → ORIGINAL SENTENCE → NEW CONTEXT → RETRIEVE → RETURN

## Sentence Meaning Bridge
ORIGINAL SENTENCE → attempt meaning → meaningful chunks → WHO/WHAT → DOES WHAT → key relationship/chunk → extra information → simple-English clarification → optional Chinese → WHOLE SENTENCE MEANING

Separate comprehension from English expression.

## Gist
IMPORTANT DETAILS → RELATIONSHIPS → BIG IDEA → GIST

Do not infer comprehension from fluent oral reading.

## Personal Banks
### Word Bank
Store word, original sentence, source text, child-friendly meaning, encounters, retrieval history, support history, transfer evidence, status.

### Chunk Bank
Store chunk, whole meaning, original sentence, source text, retrieval and transfer history.

### Fluency Bank
Store slow/misread/stuck/self-corrected words and difficult phrases.

Suggested status:
NEW / LEARNING / ALMOST_MINE / INDEPENDENT

## Retrieval and Spacing
MEANING RETRIEVAL → ORIGINAL SENTENCE → CONTEXT CHOICE/FILL → CHUNK RETRIEVAL → NEW SENTENCE → EXPLAIN MEANING → USE IN NEW CONTEXT → RETURN TO ORIGINAL TEXT

Optional schedule:
Day 1 / Day 2 / Day 4 / Day 7 / Day 14
This is an instructional design choice, not a universal formula.

## Transfer Before Reteach
When a learned word/chunk appears later:
1. test retrieval first
2. if successful independently, record transfer
3. if not, give minimum support and update status

## Real-Time Teacher Input
Teacher may tag:
HARD_TO_DECODE / READS_SLOWLY / UNKNOWN_WORD_MEANING / UNKNOWN_CHUNK / SENTENCE_MEANING / READ_ALOUD_NEEDED / PRACTICE_NEEDED

Generate only needed modules:
Decode / Words / Chunks / Sentences / Read Aloud / Practice

Teacher observes first. AI generates second.

## Practice Design
Use only actual barriers:
vocabulary retrieval / word in context / chunk meaning / sentence meaning / gist / new-context transfer

Avoid filler.

## Success Criteria
Prefer evidence that the learner can:
- read target words more automatically
- retrieve meanings
- understand chunks
- explain sentence meaning
- identify gist
- reread with less support
- recognize/use learned language in new text

## Output Format
A. Cold Read Evidence
B. Barrier Map
C. Today's Focus
D. Learning Modules
E. Retrieval Plan
F. Reread
G. Evidence of Change
H. Bank Updates
I. Transfer Check

## Common Mistakes
Avoid:
- vocabulary preview before cold read
- treating every hard word as phonics
- treating every unknown item as vocabulary
- immediate full translation
- teaching too many words deeply
- splitting chunks into isolated words
- measuring only speed
- practice disconnected from source text
- reteaching without testing retrieval first
- saving correctness without support level

## Core Reminder
> Authentic text → real barrier → targeted support → retrieval → reread → transfer.
