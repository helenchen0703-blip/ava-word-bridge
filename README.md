# Word Bridge

A teacher-guided AI learning support project for Grade 4 multilingual learners.

## What this project is

Word Bridge is designed to help teachers use real classroom evidence before asking AI to generate instructional support.

Core principle:

> Teacher observes first. AI generates second.

The school curriculum decides what the student learns.  
Evidence helps determine what support the student needs.

## Open-Source Skills

### 1. BRIDGE Learning Support

Use this skill when analyzing authentic school tasks, diagnosing learning barriers, selecting the minimum necessary scaffold, fading support, and returning the student to the original task.

[View SKILL.md](./skills/bridge-learning-support/SKILL.md)

### 2. English Growth

Use this skill when turning authentic English texts and classroom observations into long-term growth in decoding, fluency, vocabulary, chunks, sentence meaning, gist, retrieval, rereading, and transfer.

[View SKILL.md](./skills/english-growth/SKILL.md)

## Learning System

The broader Learning System includes:

- BRIDGE Learning Agent
- English Growth Agent
- Real-Time Learning Pack Generator
- Word Bank / Chunk Bank / Fluency Evidence
- Teacher Review and Student Practice

## Instructional Ideas Behind the Project

The project draws on ideas from:

- Science of Reading
- Simple View of Reading
- Scarborough's Reading Rope
- Scaffolding and Zone of Proximal Development
- Formative Assessment
- Academic Language / WIDA
- Retrieval Practice
- Transfer and Independence

## Privacy

Student-identifying information should not be stored in the public repository.

Examples and learner profiles should remain anonymized.
